---
title: "List sandboxes"
api: "GET https://api.runpod.io/v2/sandboxes"
authMethod: "bearer"
description: "List the live Runpod sandboxes owned by the authenticated user, filtered by lifecycle state or by labels. Terminated sandboxes are excluded by default."
---

Returns the authenticated user's live sandboxes. Terminated sandboxes are excluded unless you set `state=TERMINATED`. A terminated sandbox stays readable by ID either way. When you pass several filters, a sandbox must match all of them.

### Query parameters

<ParamField query="state" type="enum<string>">
  Only return sandboxes in this lifecycle state. One of `CREATING`, `RUNNING`, `TERMINATED`, or `FAILED`.
</ParamField>

<ParamField query="labels" type="string[]">
  Only return sandboxes carrying every one of these labels, each written as `key=value`. Keys and values match exactly, with no wildcard or prefix matching. Repeat the parameter for multiple labels, for example `?labels=project=checkout&labels=env=staging`.
</ParamField>

### Response

<ResponseField name="sandboxes" type="Sandbox[]" required>
  The matching sandboxes. See [Get a sandbox](/api-reference-v2/sandboxes/get-a-sandbox) for the fields of each sandbox.
</ResponseField>

### Errors

| Status | Meaning |
| --- | --- |
| `401` | The API key is missing or invalid. |
| `403` | The API key doesn't have access to sandboxes. |
| `429` | Too many requests. Retry after a delay. |

<RequestExample>

```bash cURL
curl --request GET \
  --url "https://api.runpod.io/v2/sandboxes?state=RUNNING&labels=project=quickstart" \
  --header "Authorization: Bearer $RUNPOD_API_KEY"
```

```python Python
import os
import requests

response = requests.get(
    "https://api.runpod.io/v2/sandboxes",
    headers={"Authorization": f"Bearer {os.environ['RUNPOD_API_KEY']}"},
    params={"state": "RUNNING", "labels": ["project=quickstart"]},
)
print(response.json())
```
