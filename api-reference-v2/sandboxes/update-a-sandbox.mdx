---
title: "Update a sandbox's timeouts"
api: "PATCH https://api.runpod.io/v2/sandboxes/{id}"
authMethod: "bearer"
description: "Change a running Runpod sandbox's idle timeout. The new idle deadline is recalculated from the sandbox's last recorded activity, not from now."
---

Changes the idle timeout of a running sandbox. The new `idleExpiresAt` is calculated from the sandbox's `lastActivityAt`, not from the time of the request.

Values above your account's maximum are clamped to it, and values under 90 seconds are raised to 90. Read the response for the value applied.

To change the maximum lifetime, use [Extend a sandbox's lifetime](/api-reference-v2/sandboxes/extend-a-sandbox).

### Path parameters

<ParamField path="id" type="string" required>
  The sandbox ID.
</ParamField>

### Body

<ParamField body="idleTimeoutSeconds" type="integer">
  New idle timeout in seconds.
</ParamField>

### Response

Returns the updated sandbox. See [Get a sandbox](/api-reference-v2/sandboxes/get-a-sandbox) for all fields.

### Errors

| Status | Meaning |
| --- | --- |
| `400` | The request is malformed. |
| `401` | The API key is missing or invalid. |
| `403` | The API key doesn't have access to sandboxes. |
| `404` | No sandbox with this ID exists on your account. |
| `422` | The request can't be applied, for example the sandbox is no longer running. |
| `429` | Too many requests. Retry after a delay. |

<RequestExample>

```bash cURL
curl --request PATCH \
  --url https://api.runpod.io/v2/sandboxes/SANDBOX_ID \
  --header "Authorization: Bearer $RUNPOD_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"idleTimeoutSeconds": 1800}'
```

```python Python
import os
import requests

response = requests.patch(
    "https://api.runpod.io/v2/sandboxes/SANDBOX_ID",
    headers={"Authorization": f"Bearer {os.environ['RUNPOD_API_KEY']}"},
    json={"idleTimeoutSeconds": 1800},
)
print(response.json()["idleExpiresAt"])
```
