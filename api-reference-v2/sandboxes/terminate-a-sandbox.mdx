---
title: "Terminate a sandbox"
api: "DELETE https://api.runpod.io/v2/sandboxes/{id}"
authMethod: "bearer"
description: "Terminate a Runpod sandbox to release its compute and stop billing. Termination is final, safe to retry, and the record stays readable by ID."
---

Terminates a sandbox and releases its compute. Billing stops at termination.

Termination is final: a terminated sandbox can't be restarted. The sandbox record stays readable through [Get a sandbox](/api-reference-v2/sandboxes/get-a-sandbox) afterward, with `terminationReason` and `terminatedAt` set.

Terminating a sandbox that is already terminated succeeds and has no effect, so it's safe to retry this request.

### Path parameters

<ParamField path="id" type="string" required>
  The sandbox ID.
</ParamField>

### Response

Returns `204` with no body.

### Errors

| Status | Meaning |
| --- | --- |
| `401` | The API key is missing or invalid. |
| `403` | The API key doesn't have access to sandboxes. |
| `404` | No sandbox with this ID exists on your account. |
| `429` | Too many requests. Retry after a delay. |

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.runpod.io/v2/sandboxes/SANDBOX_ID \
  --header "Authorization: Bearer $RUNPOD_API_KEY"
```

```python Python
import os
import requests

response = requests.delete(
    "https://api.runpod.io/v2/sandboxes/SANDBOX_ID",
    headers={"Authorization": f"Bearer {os.environ['RUNPOD_API_KEY']}"},
)
print(response.status_code)  # 204
```
