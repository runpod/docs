Set the `gpu` parameter on `@app.queue`, `@app.api`, or `@app.task` to choose the hardware a resource runs on. You can use a short name, a GPU pool, an exact device, or a list of these.

```python
import runpod
from runpod import GpuGroup, GpuType

app = runpod.App("gpu-demo")

@app.queue(gpu="4090")                          # Short name
def a(): ...

@app.queue(gpu=GpuGroup.AMPERE_80)              # Any GPU in a pool
def b(): ...

@app.queue(gpu=GpuType.NVIDIA_H100_80GB_HBM3)   # One exact device
def c(): ...

@app.queue(gpu=["H100", GpuGroup.AMPERE_80])    # Several options
def d(): ...
```

If you don't set `gpu` or `cpu`, the resource can run on any GPU.

## How GPU strings are matched

The SDK resolves a string in this order and raises an error listing the valid options if nothing matches:

1. `"any"`, which allows every GPU.
2. A pool ID such as `"ADA_24"` (case-insensitive).
3. An exact device name such as `"NVIDIA B200"`, or its enum name such as `"NVIDIA_B200"`.
4. A fragment of a device name, such as `"4090"`, `"B200"`, or `"h100"`. Every device whose name contains the fragment matches, so `"H100"` selects all three H100 variants.

Because strings are checked when the decorator runs, a typo fails when you import your module rather than at deploy time.

<Note>
  Serverless endpoints (queue and API resources) select hardware by pool. If you pass an exact device, the endpoint uses that device's pool, so workers can run on any GPU in the same pool. Tasks run on Pods, which select by device.
</Note>

## Choose a GPU

- **For development**, use `GpuGroup.ANY` or a list of several pools so workers start quickly even when one GPU type is scarce.
- **For production**, pin a specific pool or device so performance and cost are predictable.
- **For multiple GPUs per worker**, combine `gpu` with `gpu_count`, for example `gpu="H100", gpu_count=4`.
- **For a minimum driver version**, set `min_cuda_version`, for example `min_cuda_version="12.8"`.

For pricing by GPU, see [Serverless pricing](/serverless/pricing). To check current prices and stock by data center from your terminal, run `rp catalog GPU_NAME --serverless`. See [rp catalog](/sdk/cli#rp-catalog).
