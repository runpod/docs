The `rp` CLI is installed with the `runpod` Python package. Use it to authenticate, develop and deploy apps, and work with Pods and SSH keys. The same CLI is also available under the name `runpod`, so `rp flash deploy` and `runpod flash deploy` are equivalent.

<Note>
  The `rp` CLI is separate from [`runpodctl`](/runpodctl/overview), which is a standalone binary with a different set of commands.
</Note>

## Command summary

```bash
# Auth
rp login

# Apps
rp flash init my-app
rp flash dev main.py
rp flash deploy
rp flash app list
rp flash env list --app my-app
rp flash undeploy --app my-app

# SSH
rp ssh add
rp ssh list
rp ssh POD_ID

# Pods
rp pod list
rp pod create
rp pod connect POD_ID
```

App lifecycle commands live under `rp flash`. Account, SSH, and Pod commands live at the root. Run `rp --help` or `rp COMMAND --help` for details on any command.

## rp login

Authenticate with Runpod and save your credentials to `~/.runpod/config.toml`:

```bash
rp login                       # Approve access in your browser
rp login --api-key API_KEY     # Store a key directly
rp login --profile staging     # Save credentials to a named profile
```

Use `--profile PROFILE_NAME` with either login method to update only that profile. The default profile is `default`.

## rp flash init

Scaffold a new app project:

```bash
rp flash init my-app
```

## rp flash dev

Run a live development session for the app defined in a file:

```bash
rp flash dev main.py
```

The session creates temporary endpoints, runs the function marked with `@runpod.local_entrypoint`, and streams worker logs back to your terminal. Edit your code and re-run to iterate.

When you press Ctrl-C, the session waits for the running entrypoint to finish and then deletes its endpoints. If cleanup fails, the command exits with an error and lists the endpoint IDs you need to delete.

<Tip>
  App discovery imports your modules synchronously. Keep blocking work inside an entrypoint or a remote function. If discovery hangs on an import, interrupt it with Ctrl-C.
</Tip>

## rp flash deploy

Build and deploy the app in the current project:

```bash
rp flash deploy
```

This creates production endpoints for every resource in the app.

## rp flash app

List the apps you've deployed:

```bash
rp flash app list
```

## rp flash env

List the environments for an app:

```bash
rp flash env list --app my-app
```

## rp flash undeploy

Delete the endpoints for an app's environment:

```bash
rp flash undeploy --app my-app
```

<Warning>
  Undeploying an app doesn't delete network volumes it created. Volumes continue to incur storage charges until you delete them. See [Network volumes](/storage/network-volumes) to learn how to delete a volume.
</Warning>

## rp ssh

Manage SSH keys on your account and connect to Pods:

```bash
rp ssh add       # Add a key to your account
rp ssh list      # List the keys on your account
rp ssh POD_ID    # Open a terminal on a Pod
```

`rp ssh add` generates a new key if you don't pass one. To use an existing key, pass `--key` or `--key-file`. Keys are stored in `~/.runpod/ssh/`.

## rp pod

Work with Pods:

```bash
rp pod list
rp pod create
rp pod connect POD_ID    # Same as rp ssh POD_ID
```
