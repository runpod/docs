The `rp` CLI is installed with the `runpod` Python package. Use it to authenticate, develop and deploy apps, and work with Pods and SSH keys. The same CLI is also available under the name `runpod`, so `rp flash deploy` and `runpod flash deploy` are equivalent.

<Note>
  The `rp` CLI is separate from [`runpodctl`](/runpodctl/overview), which is a standalone binary with a different set of commands.
</Note>

## Command summary

```bash
# Auth
rp login

# Apps
rp flash init my-app
rp flash dev main.py
rp flash deploy
rp flash app list
rp flash env list --app my-app
rp flash logs --follow
rp flash undeploy --app my-app
rp flash update

# SSH
rp ssh add
rp ssh list
rp ssh POD_ID

# Pods
rp pod list
rp pod create
rp pod connect POD_ID
```

App lifecycle commands live under `rp flash`. Account, SSH, and Pod commands live at the root. Run `rp --help` or `rp COMMAND --help` for details on any command.

## rp login

Authenticate with Runpod and save your credentials to `~/.runpod/config.toml`:

```bash
rp login                       # Approve access in your browser
rp login --api-key API_KEY     # Store a key directly
rp login --profile staging     # Save credentials to a named profile
```

Use `--profile PROFILE_NAME` with either login method to update only that profile. The default profile is `default`.

## rp flash init

Scaffold a new app project:

```bash
rp flash init my-app
```

## rp flash dev

Run a live development session for the app defined in a file:

```bash
rp flash dev main.py
```

The session creates temporary endpoints, runs the function marked with `@runpod.local_entrypoint`, and streams worker logs back to your terminal. Edit your code, then press Enter to re-run. Workers pick up the new code automatically.

To run the entrypoint once and exit, which is useful for scripts and CI, add `--once`:

```bash
rp flash dev main.py --once
```

When you press Ctrl-C, the session waits for the running entrypoint to finish and then deletes its endpoints. If cleanup fails, the command exits with an error and lists the endpoint IDs you need to delete.

<Tip>
  App discovery imports your modules synchronously. Keep blocking work inside an entrypoint or a remote function. If discovery hangs on an import, interrupt it with Ctrl-C.
</Tip>

## rp flash deploy

Build and deploy the app in the current project:

```bash
rp flash deploy
```

This creates production endpoints for every resource in the app. Common flags:

| Flag | Description |
| --- | --- |
| `--env ENVIRONMENT_NAME` | Deploy to a specific environment. |
| `--exclude PACKAGES` | Leave packages out of the build, for example `--exclude scipy,pandas`. |
| `--python-version VERSION` | Build for a specific Python version, for example `--python-version 3.12`. |
| `--build-only` | Build the deployment artifact without deploying it. This replaces `flash build`. |

## rp flash app

Manage the apps you've deployed:

```bash
rp flash app list              # List your apps
rp flash app get APP_NAME      # Show an app's details
rp flash app delete APP_NAME   # Delete an app
```

## rp flash env

Manage an app's environments, such as `dev`, `staging`, and `production`:

```bash
rp flash env list --app my-app       # List environments
rp flash env get ENVIRONMENT_NAME    # Show an environment's endpoints and status
rp flash env add ENVIRONMENT_NAME    # Create an environment
rp flash env delete ENVIRONMENT_NAME # Delete an environment
```

## rp flash logs

Show logs from your app's workers:

```bash
rp flash logs              # Show recent logs
rp flash logs --follow     # Stream new logs as they arrive
rp flash logs --tail 100   # Show the last 100 lines
```

## rp flash undeploy

Delete the endpoints for an app's environment:

```bash
rp flash undeploy --app my-app
```

<Warning>
  Undeploying an app doesn't delete network volumes it created. Volumes continue to incur storage charges until you delete them. See [Network volumes](/storage/network-volumes) to learn how to delete a volume.
</Warning>

## rp flash update

Update the SDK and CLI to the latest version:

```bash
rp flash update
```

## Secrets and registries

Store secrets that your app reads with `runpod.Secret`, and save credentials for private container registries:

```bash
rp secret add SECRET_NAME       # Create a secret
rp secret list                  # List secrets
rp secret delete SECRET_NAME    # Delete a secret

rp registry add                 # Save credentials for a private registry
rp registry list                # List saved registries
rp registry delete REGISTRY     # Delete saved credentials
```

## rp ssh

Manage SSH keys on your account and connect to Pods:

```bash
rp ssh add       # Add a key to your account
rp ssh list      # List the keys on your account
rp ssh POD_ID    # Open a terminal on a Pod
```

`rp ssh add` generates a new key if you don't pass one. To use an existing key, pass `--key` or `--key-file`. Keys are stored in `~/.runpod/ssh/`.

## rp pod

Work with Pods:

```bash
rp pod list
rp pod create
rp pod connect POD_ID    # Same as rp ssh POD_ID
```
