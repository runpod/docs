## Python

The Python SDK requires Python 3.10 or higher. The same `runpod` package also includes the app SDK (formerly Flash) and the `rp` CLI. See the [Runpod SDK overview](/sdk/overview) for everything the package can do.

### Install

Create a virtual environment and install the SDK:

<Tabs>
<Tab title="macOS/Linux">
```bash
python3 -m venv venv
source venv/bin/activate
pip install runpod
```
</Tab>

<Tab title="Windows">
```bash
python -m venv venv
venv\Scripts\activate
pip install runpod
```
</Tab>
</Tabs>

To verify the installation:

```bash
python -c "import runpod; print(runpod.__version__)"
```

### Configure your API key

Set your API key as an environment variable and reference it in your code:

```python
import runpod
import os

runpod.api_key = os.getenv("RUNPOD_API_KEY")
```

<Warning>
Never hardcode your API key directly in your code. Always use environment variables or a secrets manager.
</Warning>

For more information, see the [Python SDK on GitHub](https://github.com/runpod/runpod-python).

## JavaScript

The JavaScript SDK requires Node.js 20 or higher. It supports ES modules and CommonJS, and includes TypeScript types.

### Install

```bash
npm install --save runpod-sdk
# or
yarn add runpod-sdk
```

### Configure your API key

```javascript
import runpodSdk from "runpod-sdk";
const { RUNPOD_API_KEY, ENDPOINT_ID } = process.env;

const runpod = runpodSdk(RUNPOD_API_KEY);
const endpoint = runpod.endpoint(ENDPOINT_ID);
```

The same package also includes a typed client for the [REST API](/api-reference-v2/overview), so you can manage Pods, endpoints, templates, and network volumes from the same code:

```javascript
const { data: pods } = await runpod.api.GET("/v2/pods");
```

If you only need the REST API client, install [`@runpod/typescript-api-sdk`](https://www.npmjs.com/package/@runpod/typescript-api-sdk) instead.

<Note>
Version 2.0.0 requires Node.js 20 or higher, and HTTP errors throw a `RunpodServerlessError`. The `endpoint` methods are unchanged from 1.x. To stay on 1.x, install `runpod-sdk@1`.
</Note>

For more information, see the [JavaScript SDK on GitHub](https://github.com/runpod/js-sdk) and the [npm package](https://www.npmjs.com/package/runpod-sdk).

## Go

### Install

```bash
go get github.com/runpod/go-sdk
go mod tidy
```

### Configure your API key

```go
package main

import (
    "os"

    "github.com/runpod/go-sdk/pkg/sdk/config"
    rpEndpoint "github.com/runpod/go-sdk/pkg/sdk/endpoint"
)

func main() {
    apiKey := os.Getenv("RUNPOD_API_KEY")
    endpointId := os.Getenv("ENDPOINT_ID")

    endpoint, err := rpEndpoint.New(
        &config.Config{ApiKey: &apiKey},
        &rpEndpoint.Option{EndpointId: &endpointId},
    )
    if err != nil {
        panic(err)
    }

    // Use the endpoint...
}
```

For more information, see the [Go SDK on GitHub](https://github.com/runpod/go-sdk) and the [Go package documentation](https://pkg.go.dev/github.com/runpod/go-sdk/pkg/sdk).
