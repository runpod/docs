This page covers the most common problems when you connect and use external compute, and what to do about each.

## Verification failed

When a machine's status is **Verification failed**, the automated hardware checks found a problem with the machine or its configuration. Running verification again without changing anything gives the same result. Fix the underlying issue first, then retry verification.

## Machine stuck in pending install

**Pending install** means Runpod hasn't heard from the host agent yet. To fix this:

1. Make sure the install command finished without errors. If you aren't sure, run it again.
2. Check that the machine can make outbound connections to the internet.
3. Confirm that you rebooted the machine after you configured networking.

## Machine stuck in verification in progress

Verification normally finishes on its own. If a machine stays in **Verification in progress** much longer than expected, the problem is most likely on the Runpod side, not your hardware. [Contact the Runpod team](#get-help) with the machine name.

## Machine doesn't appear in the GPU picker

If you can't find your machine's GPU when you deploy a Pod:

- Check that the machine's status is **Online** on the **External compute** page. Machines in any other status can't accept Pods.
- Make sure you've selected the organization that owns the machine in the console.
- Check whether every GPU on your machines is already in use. The **External compute** page shows current usage.

## Get help

Runpod Hybrid Cloud is in alpha, and each customer works with the Runpod team during onboarding. If these steps don't fix the problem, contact your Runpod onboarding contact and include the machine name and its current status.
