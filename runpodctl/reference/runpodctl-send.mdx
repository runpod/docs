Transfer files or folders from your local machine to a Pod or another computer using a secure peer-to-peer connection. The `send` command prints a code, and you complete the transfer by running [`runpodctl receive`](/runpodctl/reference/runpodctl-receive) with that code on the other machine.

<RequestExample>
```bash Command
runpodctl send <fileOrFolder> [flags]
```
</RequestExample>

## Examples

Send a file and get a one-time code:

```bash
runpodctl send ./model.safetensors
```

The command prints a code such as `5254-respect-amen-emotion-14`. The number at the end identifies the relay server for the transfer. On the Pod or other computer, run `receive` with the exact code, including that number:

```bash
runpodctl receive 5254-respect-amen-emotion-14
```

Send a folder using your own codephrase:

```bash
runpodctl send ./my-dataset --code my-long-secret-phrase
```

The command prints your codephrase with a relay number appended, such as `my-long-secret-phrase-14`. The receiver must enter that printed value, not the bare codephrase.

## Arguments

<ResponseField name="<fileOrFolder>" type="string" required>
The path to the file or folder you want to send. Can be a single file or an entire directory.
</ResponseField>

## Flags

<ResponseField name="--code" type="string">
A custom codephrase to use instead of a randomly generated one-time code. The codephrase must be at least 6 characters long. Only the characters after the fifth one stay secret, so use a long phrase. Unlike a generated code, a custom codephrase isn't one-time. The `send` command appends a relay number to it. The receiver must enter the printed `CODEPHRASE-RELAY_NUMBER` value with the [`receive`](/runpodctl/reference/runpodctl-receive) command.
</ResponseField>
