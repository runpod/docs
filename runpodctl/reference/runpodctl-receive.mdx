Receive files or folders sent from another machine using a secure peer-to-peer connection. Use the code that [`runpodctl send`](/runpodctl/reference/runpodctl-send) printed on the sending machine.

<RequestExample>
```bash Command
runpodctl receive <code>
```
</RequestExample>

## Examples

Receive files using the one-time code printed by `runpodctl send`:

```bash
runpodctl receive 5254-respect-amen-emotion-14
```

If the sender ran `runpodctl send --code my-long-secret-phrase` and the command printed `my-long-secret-phrase-14`, receive the files with the printed value:

```bash
runpodctl receive my-long-secret-phrase-14
```

## Arguments

<ResponseField name="<code>" type="string" required>
The exact code printed by the [`send`](/runpodctl/reference/runpodctl-send) command, including the relay number at the end. If the sender used `--code`, enter the printed `CODEPHRASE-RELAY_NUMBER` value rather than the bare codephrase.
</ResponseField>
