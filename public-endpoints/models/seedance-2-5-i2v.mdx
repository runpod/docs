Seedance 2.5 Image-to-Video is ByteDance's image-to-video model. It animates a start image into a 4-30 second video at up to 4K resolution, guided by a text prompt. Native audio is generated alongside the video. Add an optional last frame to control where the video ends.

| | |
|---|---|
| **Endpoint** | `https://api.runpod.ai/v2/16jsvx5ncmm24x/runsync` |
| **Model** | `bytedance/seedance-2.5` |
| **Pricing** | \$0.18–\$1.80 per second |
| **Type** | Video generation (image-to-video) |

## Request

All parameters are passed within the `input` object in the request body.

<ParamField body="input.prompt" type="string" required>
  Text description of the desired video motion and content.
</ParamField>

<ParamField body="input.image" type="string" required>
  URL of the start frame image to animate.
</ParamField>

<ParamField body="input.last_image" type="string">
  URL of an optional last frame image. The video transitions from the start image to this frame.
</ParamField>

<ParamField body="input.duration" type="integer" default="5">
  Video duration in seconds. Range: 4-30 seconds.
</ParamField>

<ParamField body="input.resolution" type="string" default="720p">
  Output resolution. Options: `480p`, `720p`, `1080p`, `4k`.
</ParamField>

<ParamField body="input.aspect_ratio" type="string" default="16:9">
  Aspect ratio. Options: `21:9`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`.
</ParamField>

<ParamField body="input.generate_audio" type="boolean" default="true">
  Generate native audio, such as dialogue, sound effects, and music, alongside the video.
</ParamField>

<ParamField body="input.seed" type="integer" default="-1">
  Seed for reproducible results. Set to -1 for random.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Unique identifier for the request.
</ResponseField>

<ResponseField name="status" type="string">
  Request status. Returns `COMPLETED` on success, `FAILED` on error.
</ResponseField>

<ResponseField name="output" type="object">
  The generation result containing the video URL and cost.

  <ResponseField name="output.video_url" type="string">
    URL of the generated video. This URL expires after 7 days.
  </ResponseField>

  <ResponseField name="output.cost" type="float">
    Cost of the generation in USD.
  </ResponseField>
</ResponseField>

<ResponseExample>

<Warning>
Video URLs expire after 7 days. Download and store generated videos immediately if you need to keep them.
</Warning>

## Cost calculation

Seedance 2.5 Image-to-Video charges per second of output video, based on resolution:

| Resolution | Cost per second |
|------------|----------------|
| 480p | \$0.18 |
| 720p | \$0.36 |
| 1080p | \$0.90 |
| 4K | \$1.80 |

Example: A 5-second 720p video costs \$1.80.
