Veo 3.1 Fast is Google's image-to-video model. It animates a reference image, guided by a text prompt, into a 4, 6, or 8 second video at up to 4K resolution, with optional synchronized audio.

<Card title="Try in playground" icon="play" href="https://console.runpod.io/hub/playground/video/google-veo3-1-fast-i2v" horizontal>
  Test Veo 3.1 Fast I2V in the Runpod Hub playground.
</Card>

| | |
|---|---|
| **Endpoint** | `https://api.runpod.ai/v2/google-veo3-1-fast-i2v/runsync` |
| **Pricing** | \$0.15/s with audio, \$0.10/s without audio |
| **Type** | Video generation |

## Request

All parameters are passed within the `input` object in the request body.

<ParamField body="input.image" type="string" required>
  URL of the input image to animate.
</ParamField>

<ParamField body="input.prompt" type="string" required>
  Text describing the desired motion and scene.
</ParamField>

<ParamField body="input.last_image" type="string">
  URL of an optional final frame for the video to end on.
</ParamField>

<ParamField body="input.aspect_ratio" type="string" default="16:9">
  Video aspect ratio. Options: `16:9`, `9:16`.
</ParamField>

<ParamField body="input.duration" type="integer" default="6">
  Video duration in seconds. Options: `4`, `6`, `8`.
</ParamField>

<ParamField body="input.resolution" type="string" default="720p">
  Output resolution. Options: `720p`, `1080p`, `4k`.
</ParamField>

<ParamField body="input.generate_audio" type="boolean" default="true">
  Generate synchronized audio with the video.
</ParamField>

<ParamField body="input.negative_prompt" type="string">
  Elements to exclude from the output.
</ParamField>

<ParamField body="input.seed" type="integer">
  Seed for reproducible generation.
</ParamField>

<RequestExample>
```bash cURL

    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.runpod.ai/v2/google-veo3-1-fast-i2v/runsync",
    headers={
        "Authorization": f"Bearer {RUNPOD_API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "input": {
            "image": "https://image.runpod.ai/assets/google/veo3-1-fast-i2v.png",
            "prompt": "A singer in a silver gown performs under a soft spotlight as the camera pans from a close-up to a wide shot of the stage.",
            "duration": 6,
            "resolution": "720p",
            "generate_audio": True,

)

print(result["output"]["result"])
```

</RequestExample>

Video generation can take longer than a synchronous request waits. If `/runsync` returns a status of `IN_PROGRESS` or `IN_QUEUE`, poll `/status` with the returned job ID, or submit with `/run` from the start. See [Make API requests](/public-endpoints/requests).

## Response

<ResponseField name="id" type="string">
  Unique identifier for the request.
</ResponseField>

<ResponseField name="status" type="string">
  Request status. Returns `COMPLETED` on success, `FAILED` on error.
</ResponseField>

<ResponseField name="delayTime" type="integer">
  Time in milliseconds the request spent in queue before processing began.
</ResponseField>

<ResponseField name="executionTime" type="integer">
  Time in milliseconds the model took to generate the video.
</ResponseField>

<ResponseField name="output" type="object">
  The generation result containing the video URL and cost.

  <ResponseField name="output.result" type="string">
    URL of the generated video. This URL expires after 7 days.
  </ResponseField>

  <ResponseField name="output.cost" type="float">
    Cost of the generation in USD.
  </ResponseField>
</ResponseField>


<Warning>
Video URLs expire after 7 days. Download and store generated videos immediately if you need to keep them.
</Warning>

## Cost calculation

Veo 3.1 Fast I2V charges per second of video, and the rate depends on whether you generate audio:

| Duration | With audio (\$0.15/s) | Without audio (\$0.10/s) |
|----------|-----------|---------------|
| 4 seconds | \$0.60 | \$0.40 |
| 6 seconds | \$0.90 | \$0.60 |
| 8 seconds | \$1.20 | \$0.80 |
